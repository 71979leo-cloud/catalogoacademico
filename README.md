# Catálogo de recursos académicos

## Descripción

El proyecto **Catálogo de recursos académicos** consiste en 
desarrollar la estructura inicial de una aplicación que permitirá 
organizar diferentes recursos utilizados para el aprendizaje. En un 
futuro, el sistema podrá registrar y consultar libros, sitios web, 
videos, artículos y herramientas de software.

En esta primera etapa se prepara principalmente la estructura de 
archivos, el entorno de trabajo y la documentación necesaria para 
continuar con el desarrollo posteriormente.

## Objetivo

Crear una estructura organizada para el proyecto, dejando preparado el 
entorno de desarrollo y la documentación necesaria para facilitar la 
implementación de las funciones del sistema en futuras etapas.

## Estructura general

El proyecto estará organizado de la siguiente manera:

- **Archivos de Python:** contendrán posteriormente la lógica y las 
funciones de la aplicación.
- **README.md:** contiene la descripción, objetivo e instrucciones 
principales del proyecto.
- **requirements.txt:** registra las dependencias necesarias para 
ejecutar el proyecto.
- **.gitignore:** indica los archivos y carpetas que Git no debe 
incluir en el repositorio, como `.venv`.
- **.venv:** entorno virtual utilizado para instalar las dependencias 
del proyecto de manera independiente.

## Tecnologías utilizadas

- **Python:** lenguaje de programación principal del proyecto.
- **Visual Studio Code:** entorno utilizado para desarrollar y 
organizar los archivos.
- **Git:** herramienta utilizada para llevar el control de versiones.
- **GitHub:** plataforma utilizada para almacenar el repositorio y 
colaborar en el proyecto.
- **venv:** herramienta de Python utilizada para crear un entorno 
virtual.

## Instrucciones para preparar el entorno

1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Crear el entorno virtual con `python -m venv .venv`.
4. Activar el entorno virtual.
5. Instalar las dependencias utilizando `pip install -r requirements.
txt`.
6. Verificar que el entorno esté correctamente configurado antes de 
comenzar a trabajar.

## Dependencias

Las librerías necesarias para el funcionamiento del proyecto estarán 
registradas en el archivo `requirements.txt`. Esto permite que 
cualquier integrante pueda instalar las mismas dependencias sin 
necesidad de compartir la carpeta `.venv`.

Conforme avance el desarrollo del **Catálogo de recursos académicos**, se agregarán a este archivo las librerías que sean necesarias.

# Próximas mejoras
Mejoras propuestas
1. Búsqueda avanzada: permitir búsquedas por título, autor y palabras clave.
2. Filtros: clasificar los recursos por materia, fecha de publicación, formato e idioma.
3. Registro de recursos: permitir agregar, modificar y eliminar materiales académicos.
4. Interfaz: desarrollar una interfaz más atractiva, sencilla y fácil de utilizar.
5. Favoritos: permitir guardar los recursos académicos más utilizados.
6. Validación de datos: evitar registros incompletos o duplicados.
7. Exportación: permitir descargar el catálogo en diferentes formatos, como CSV.
8. Corrección de errores: realizar pruebas para mejorar el funcionamiento del sistema.
Prioridades
- Corto plazo: implementar búsquedas, filtros y validación de datos.
- Mediano plazo: mejorar la interfaz y la administración de recursos.
- Largo plazo: incorporar favoritos, exportación de archivos y nuevas funcionalidades.
