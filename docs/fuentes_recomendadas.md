# Fuentes recomendadas para recursos académicos

A continuación se presentan varias fuentes y plataformas que pueden servir como referencia para localizar recursos académicos de calidad:

1. Google Scholar
   - Motor de búsqueda académico orientado a artículos, tesis, libros y trabajos de investigación.
   - Útil para localizar referencias y documentos citados en contextos académicos.

2. Redalyc
   - Red de Revistas Científicas de América Latina y el Caribe.
   - Ofrece acceso a artículos y publicaciones académicas en español y portugués.

3. SciELO
   - Scientific Electronic Library Online.
   - Plataforma reconocida por su colección de revistas científicas y recursos de investigación.

4. OpenAlex
   - Base de datos abierta de literatura científica y de investigación.
   - Permite consultar publicaciones, autores, instituciones y métricas académicas.

5. MIT OpenCourseWare
   - Repositorio de materiales educativos universitarios.
   - Incluye apuntes, tareas, exámenes y recursos didácticos de alta calidad.

6. UNESCO Digital Library
   - Biblioteca digital con documentos, informes y recursos relacionados con educación, ciencia y cultura.
   - Puede incluir contenidos de valor académico y de divulgación institucional.

7. ResearchGate
   - Red social académica que facilita el intercambio de artículos, prepublicaciones y referencias.
   - Útil para encontrar investigaciones recientes y autores especializados.

8. DOAJ
   - Directory of Open Access Journals.
   - Directorio de revistas de acceso abierto con contenido académico de diversas disciplinas.

Estas fuentes complementan la búsqueda de recursos y pueden ayudar a validar la calidad, el alcance y la relevancia de los materiales incluidos en el catálogo.
