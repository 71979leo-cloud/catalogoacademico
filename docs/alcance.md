# Alcance futuro

La version inicial establece la estructura del proyecto y algunos registros de ejemplo. En versiones futuras, el sistema podria incorporar las siguientes funcionalidades:

1. Agregar, editar y eliminar recursos desde una interfaz sencilla.
2. Buscar recursos por titulo, tema, tipo, nivel o autor.
3. Filtrar y ordenar el catalogo para localizar materiales con rapidez.
4. Validar los campos obligatorios y la estructura de cada registro antes de guardarlo.
5. Importar y exportar el catalogo en formatos como JSON o CSV.
6. Guardar valoraciones y notas personales asociadas a cada recurso.
