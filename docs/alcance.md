## Funcionalidades futuras

En una versión futura, el sistema podría convertirse en una 
herramienta para organizar y consultar diferentes recursos académicos 
de una manera sencilla. Algunas de sus funcionalidades podrían ser:

- **Registrar recursos:** agregar libros, videos, artículos, páginas 
web y herramientas de software.
- **Consultar recursos:** visualizar todos los recursos académicos que 
hayan sido registrados.
- **Buscar recursos:** encontrar información por nombre, categoría, 
autor o tipo de recurso.
- **Modificar recursos:** actualizar la información de algún recurso 
registrado anteriormente.
- **Eliminar recursos:** borrar recursos que ya no sean necesarios o 
que estén desactualizados.
