1. Fecha de publicación: Indica cuándo fue creado o publicado el 
recurso académico.

2. Formato: Permite clasificarlo como PDF, página web, video, 
documento, presentación, etc.

3. Idioma: Identifica el idioma en el que se encuentra el contenido, 
como español o inglés.

4. Área académica: Permite organizar el recurso según la carrera o 
campo al que pertenece, como informática, electrónica, matemáticas o 
administración.

5. Palabras clave: Facilitan encontrar un recurso mediante conceptos 
relacionados con su contenido.

6. Disponibilidad: Indica si el recurso es gratuito, de pago o 
requiere algún tipo de acceso.

7. Nivel de dificultad: Permite identificar si el recurso es básico, 
intermedio o avanzado, según el nivel académico del lector.

8. Licencia o derechos de uso: Indica si el material puede ser 
consultado, compartido o reutilizado libremente, o si tiene restricciones 
de uso.
